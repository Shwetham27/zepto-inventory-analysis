# Zepto Inventory Analysis Using SQL

## Project Overview
This project analyzes Zepto product inventory data using MySQL to identify product categories, pricing patterns, discounts, and stock availability.

## Dataset
Zepto product inventory dataset containing product names, categories, MRP, discount percentage, available quantity, discounted selling price, weight, and out-of-stock status.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Business Questions

1. How many product records are in the dataset?
2. Which product categories have the most products?
3. Which products have the highest discount percentages?
4. Which products are out of stock?
5. What percentage of products are out of stock?
6. Which product categories have the highest average discount?
7. Which products have the highest MRP?
8. Which products are in stock but have the lowest selling prices?
9. What is the total available inventory quantity by category?
10. Which products have invalid pricing or inventory values?
11. Which categories have the highest average MRP?
12. Which products have discounts greater than 20%?
13. Which products have zero or negative pricing values?
14. How does product availability vary across categories?
15. Which products need inventory or pricing data quality checks?
    
## Key Findings
- Total product records: 3,728.
- Out-of-stock products: 453 (12.15%).
- Fruits & Vegetables had the highest average discount among categories in the analyzed results.

## Skills Demonstrated
SQL queries, aggregation, GROUP BY, ORDER BY, filtering, CASE statements, and data quality checks.
